免费数据源 + GitHub Actions 定时更新 + GitHub Pages 静态看板，任何电脑/手机可通过公网地址访问。

## 数据口径与估算说明(重要)

- **净申购金额** = ETF份额变动 × 当日收盘价。份额为沪深交易所官方日度数据，金额为标准估算口径(与券商研报一致)。
- **机构/个人拆分**：按各ETF最新定期报告(半年报/年报)的机构持有比例近似拆分，存在滞后与误差。
- **国家队(汇金)**：无免费逐日数据，曲线为基金定期报告披露的汇金持有ETF市值锚点插值，2025-06-30后为估算延伸。机构线已包含国家队。
- **二级债基指数**：Wind 885007为收费数据，此处自建(全市场混合债券型二级基金日净值增长率等权合成，基期2005-01-04=1000)，存在幸存者偏差等近似。
- 单日净申购超过该ETF前一日市值20%的异常份额变动(如份额折算)已自动剔除。
- A股各数据源均为收盘后披露的日频数据，因此①②③为每日更新；美股④为盘中高频。

## 自动更新架构

- `cn.yml`：每交易日 北京时间 20:30 / 22:30 / 次日09:10 增量抓取A股数据并提交。
- `us.yml`：美股盘前/盘中/盘后时段(覆盖北京时间约16:00-次日09:00)每10分钟抓取。
- `weekly.yml`：每周六全量重建二级债基指数并刷新持有人结构(修正分红/新基金)。
- 数据以JSON提交到 `data/`，GitHub Pages 随之自动发布。

## 本地兜底(可选)

若GitHub Actions访问国内数据源失败，可在本地Windows运行 `local_update.bat`(需已安装Python并 `pip install openpyxl tzdata`)，
再用 `git add data/ && git commit -m "data: local" && git push` 推送。可用"任务计划程序"定时执行。

## 部署方法

1. 将本目录推送为公开GitHub仓库(含全部文件)。
2. 仓库 Settings → Pages → Source 选择 "Deploy from a branch"，Branch 选 `main` / `(root)`，保存。
3. 数分钟后访问 `https://<用户名>.github.io/<仓库名>/`。
4. Actions 标签页确认三个定时工作流已启用(默认仓库创建后自动启用)。
